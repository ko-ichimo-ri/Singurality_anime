# 制作仕様と規模の見積もり

本作はアニメーション作品として制作します。
もともとは同人誌として漫画化する予定で、1編あたり約50ページを想定していました。その規模を、アニメに換算して見積もります。

## 制作方式

| 項目 | 方式 |
|---|---|
| 映像 | **2D ベクター／切り絵アニメ。** エージェント（Claude）が Python で生成する。手描きの原画・動画はない |
| キャラクターデザイン | エージェントがコードで作る（`03_design/`） |
| 声 | なし。**字幕のみ** |
| 言語 | **日本語版と英語版を同時に作る。** 映像は共通で、字幕と画面内の文字だけを差し替え、別々のファイルとして書き出す |
| BGM・効果音 | エージェントが Python で合成する（`04_sound/`） |
| 物語・セリフ | 作者が書く。英訳はエージェントが行い、作者が確認する |

- カットはそれぞれ1本の Python スクリプトで描画する。映像はいつでもコードから作り直せる
- 共通の描画の仕組みは `engine/` にまとめる

## 尺の見積もり

### 換算の根拠

- TVアニメは1話（本編約22分）で、原作漫画のおよそ40〜60ページ分を映像化することが多い
- ここから、**漫画1ページ ≈ アニメ約25〜30秒** と見積もる

### 1編あたり

| 項目 | 目安 | 計算 |
|---|---|---|
| 本編の尺 | **約22分（1,320秒）** | 50ページ × 約26秒。TVアニメ1話分に相当 |
| カット数 | **約280カット**（250〜330） | 1,320秒 ÷ 平均4.7秒。TVアニメ1話は250〜350カットが一般的 |
| シーン数 | **約15〜20シーン** | 1シーン平均60〜90秒 |

### シリーズ全体（4編）

| 項目 | 目安 |
|---|---|
| 本編の尺 | 約88分。劇場アニメ1本分に相当 |
| カット数 | 約1,100〜1,300カット |

### 使い方

- 各編の `outline.md` では、ページではなく **秒** で配分する（合計1,320秒）
- 漫画で考えたメモを移すときは、**1ページ ≈ 26秒** で換算する
- 3編が交差する場面は、同じ出来事のカットを別の編で流用できる候補になる。コードなので、視点やカメラだけ変えて描き直すこともできる（`02_crossroads/` を参照）

## ID のルール（制作）

| 対象 | 形式 | 例 |
|---|---|---|
| カット | `<編コード>_c<3桁>` | `OS_c001` |

- カット番号は本編の頭から通し番号で振る
- あとで間にカットを足すときは、アニメ制作の慣例にならい `OS_c012A` のようにアルファベットを付ける
- シーンファイルには、そのシーンに含まれるカットの範囲を書く（例：`cuts: OS_c010-OS_c025`）

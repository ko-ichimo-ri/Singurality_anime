# 設定資料（4編共通）

キャラクター・小物・舞台・色のデザインです。デザインはエージェントがコードで作ります。人物や場所は複数の編で使うため、編ごとではなくここにまとめます。

| フォルダ | 中身 |
|---|---|
| characters/<name>/ | キャラクターのデザイン。<name> は `01_characters/` のファイル名とそろえる |
| props/ | 小物・メカ・ロボット |
| locations/ | 舞台（背景）。`00_series/world/locations.md` と対応させる |
| color/ | 色の設計（全体のパレット、編ごとの色の流れ） |

## キャラクター1人分のファイル

```
characters/<name>/
  design.md       デザインの考え方、特徴、作者からの修正メモ
  model.py        形・色・表情パーツ・関節の定義。カットのスクリプトはこれを読み込んで描く
  sheet.png       設定画（model.py から生成する。正面・横・表情集など）
```

- 設定画（sheet.png）は、確認用の資料として Git で管理する。model.py を直したら生成し直す
- 作者の修正は design.md に書いてもらい、エージェントが model.py に反映する
- 小物・舞台も同じ形（design.md / model.py / sheet.png）で置く

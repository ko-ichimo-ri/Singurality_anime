# 設定資料（4編共通）

作画や美術のよりどころになる資料です。人物や場所は複数の編で使うため、編ごとではなくここにまとめます。

| フォルダ | 中身 |
|---|---|
| characters/<name>/ | キャラクター設定画、表情集、色指定。<name> は `01_characters/` のファイル名とそろえる |
| props/ | 小物・メカ・ロボットの設定画 |
| locations/ | 美術設定（舞台の設定画）。`00_series/world/locations.md` と対応させる |
| color/ | 色彩設計、カラースクリプト（編ごとの色の流れ） |

- ファイル名の例：`characters/<name>/<name>_front_v01.png`
- 版を上げるときは `_v02` のように番号を上げ、古い版は消さずに残す
- Git で管理するのは png / jpg / svg / pdf だけ。psd や clip などの作業ファイルは管理外なので、資料として残す版を png や pdf に書き出して置く（README.md の「ファイルの管理方法」を参照）

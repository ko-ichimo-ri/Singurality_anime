# 音（4編共通）

複数の編で使う音をまとめます。1つの編でしか使わない音は、各編の `production/sound/` に置きます。

| フォルダ | 中身 |
|---|---|
| music/ | 主題歌、4編で共通のBGM、テーマ曲 |
| se/ | 共通の効果音（ロボットの駆動音など、編をまたいで使う音） |

- ファイル名の例：`music/theme_main_v01.wav`
- 音声ファイルは Git の管理外。このフォルダは置き場所として使い、バックアップは外部ストレージで行う
- 曲やSEの一覧・使いどころをメモしたいときは、ここに Markdown で書く（Markdown は Git で管理される）

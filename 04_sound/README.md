# 音（4編共通）

BGM と効果音は、エージェントが Python で合成します。ここには音を作るコードを置き、生成した音声ファイル（wav など）は Git で管理しません。
1つの編でしか使わない音は、各編の `production/sound/` に置きます。

| フォルダ | 中身 |
|---|---|
| music/ | 主題曲、4編で共通のBGM |
| se/ | 共通の効果音（ロボットの駆動音など、編をまたいで使う音） |

- 1曲・1音につき1本のスクリプト（例：`music/theme_main.py`）
- 曲ごとの狙い（どの場面で使うか、雰囲気）は、スクリプトの先頭か、同じ名前の .md に書く

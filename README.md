# シンギュラリティ後の私たち

全4編のシリーズ作品の設定・構成・シーンを管理するリポジトリです。

| 公開順 | 編 | フォルダ | コード | 目安 |
|---|---|---|---|---|
| 1 | おっさん編 | [10_ossan/](10_ossan/) | `OS` | 約50ページ |
| 2 | ロボット編 | [20_robot/](20_robot/) | `RB` | 約50ページ |
| 3 | 少女編 | [30_shoujo/](30_shoujo/) | `SJ` | 約50ページ |
| 4 | その後編 | [40_after/](40_after/) | `AF` | 約50ページ |

- おっさん編・ロボット編・少女編は、同じ時間軸で並行して進みます。各編の人物がわずかに干渉しあいます
- その後編は、3編のスピンオフ的な群像劇です

## ディレクトリ構成

```
00_series/        シリーズ全体（4編共通）の設定
  concept/        テーマ、トーン、モチーフ、参考作品
  world/          世界観、年表、技術、組織、場所、用語
01_characters/    登場人物（全編共通、1人1ファイル）
02_crossroads/    3編の交差の管理
  intersections/  交差する出来事（1件1ファイル）
10_ossan/         おっさん編
20_robot/         ロボット編
30_shoujo/        少女編
40_after/         その後編
90_ideas/         まだ整理していないアイデア
99_archive/       ボツにした案（消さずにここへ移す）
troubles/         作業中のトラブル記録
```

各編のフォルダの中身は共通です。

```
synopsis.md       あらすじ
plot.md           プロット
concept.md        この編だけのテーマやトーン
outline.md        構成とページ配分
scenes/
  index.md        シーン一覧
  <ID>_<name>.md  シーン（1シーン1ファイル）
```

## 運用の考え方

- **確定した設定と、検討中の案を分けます。** 確定したものは `00_series/` に、迷っているものは `90_ideas/` に置きます
- **人物はどの編に出る人でも `01_characters/` に置きます。** 複数の編にまたがって登場するためです
- **3編が交わる出来事は `02_crossroads/intersections/` で管理します。** 「実際に何が起きたか」をそこに1か所だけ書き、各編のシーンはそれぞれの視点から描きます

## ID のルール

| 対象 | 形式 | 例 |
|---|---|---|
| シーン | `<編コード>_s<3桁>` | `OS_s010` |
| 交差 | `X<3桁>` | `X010` |

- 番号は10刻みで振ります。あとで間に追加するときは `OS_s015` のように間の番号を使います
- ファイル名は `ID_英語やローマ字の短い名前.md`（例：`OS_s010_morning-commute.md`）
- シーンに交差があるときは、シーンファイルに `crossing: X010` と書きます。交差ファイルにも、関わるシーンIDを並べます。こうしておくと、どちらからでもたどれます

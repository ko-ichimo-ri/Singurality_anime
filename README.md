# シンギュラリティ後の私たち

全4編のシリーズ**アニメーション作品**です。映像・キャラクターデザイン・BGM は、エージェント（Claude）が Python で生成する2Dアニメです。声はなく字幕のみで、**日本語版と英語版** を作ります。

設定・構成・シーンから、映像を生成するコードまでを、このリポジトリで管理します。

| 公開順 | 編 | フォルダ | コード | 尺の目安 |
|---|---|---|---|---|
| 1 | おっさん編 | [10_ossan/](10_ossan/) | `OS` | 約22分・約280カット |
| 2 | ロボット編 | [20_robot/](20_robot/) | `RB` | 約22分・約280カット |
| 3 | 少女編 | [30_shoujo/](30_shoujo/) | `SJ` | 約22分・約280カット |
| 4 | その後編 | [40_after/](40_after/) | `AF` | 約22分・約280カット |

- おっさん編・ロボット編・少女編は、同じ時間軸で並行して進みます。各編の人物がわずかに干渉しあいます
- その後編は、3編のスピンオフ的な群像劇です
- シリーズ全体で約88分です。制作方式、見積もりの根拠、映像の仕様は [00_series/production_spec.md](00_series/production_spec.md) にあります

各編のフォルダの中身は共通です。

```

  index.md        シーン一覧
  <ID>_<name>.md  シーン（1シーン1ファイル）

```

## 運用の考え方

- **確定した設定と、検討中の案を分けます。** 確定したものは `00_series/` に、迷っているものは `90_ideas/` に置きます
- **人物はどの編に出る人でも `01_characters/` に置きます。** 複数の編にまたがって登場するためです
- **3編が交わる出来事は `02_crossroads/intersections/` で管理します。** 「実際に何が起きたか」をそこに1か所だけ書き、各編のシーンはそれぞれの視点から描きます

## ID のルール

| 対象 | 形式 | 例 |
|---|---|---|
| シーン | `<編コード>_s<3桁>` | `OS_s010` |
| 交差 | `X<3桁>` | `X010` |
| カット | `<編コード>_c<3桁>` | `OS_c001` |

- シーンと交差の番号は10刻みで振ります。あとで間に追加するときは `OS_s015` のように間の番号を使います
- カットは本編の頭から通し番号です。あとで間に足すときは `OS_c012A` のようにアルファベットを付けます
- ファイル名は `ID_英語やローマ字の短い名前.md`（例：`OS_s010_morning-commute.md`）
- シーンに交差があるときは、シーンファイルに `crossing: X010` と書きます。交差ファイルにも、関わるシーンIDを並べます。こうしておくと、どちらからでもたどれます

## アニメーションの成果物

### 各編の production/

制作の流れ（脚本 → 字幕 → 絵コンテ → カットのスクリプト → 確認 → 書き出し）の順に並べています。

```
production/
  script.md           脚本（作者が書く）
  subtitles.yaml      字幕。日本語と英語を1項目に並べて書く
  storyboard/         絵コンテ（png / pdf）
  cut_list.md         カット表：全カットの一覧と進み具合
  cuts/
    _template/        カットのひな形。新しいカットはこれをコピーして作る
    OS_c001/
      cut.md          カットの情報（尺、カメラ、流用元、状態、修正メモ）
      cut.py          このカットを描画するスクリプト
  sound/              この編だけの BGM・効果音のスクリプト
  renders/            書き出し（Git 管理外）
    cuts/             カットごとの確認用
    ja/               日本語版
    en/               英語版
  master/             完成映像の記録（映像そのものは Git 管理外）
```

- 映像は共通で、字幕と画面内の文字だけを言語ごとに差し替えて、日本語版・英語版を別々に書き出します
- 複数の編で使うデザインは `03_design/`、音は `04_sound/`、描画の共通部品は `engine/` に置きます
- 3編が交わる場面では、別の編のカットを流用できます。流用するときは `cut.md` の `reuse` に流用元のカットIDを書きます

### 作者とエージェントの分担

| 作者 | エージェント |
|---|---|
| 物語・設定・プロット・シーン・脚本・日本語のセリフ | カットのスクリプト、キャラクターデザイン、BGM・効果音、英訳 |
| 書き出した映像や設定画の確認と、修正の指示 | 修正の反映 |

修正の指示は、カットなら `cut.md` の「修正メモ」、キャラクターなら `03_design/characters/<name>/design.md` に書くか、会話で伝えてください。

### ファイルの管理方法

**コード・テキストと、資料・図の画像だけを Git で管理します。** 映像や音はコードからいつでも作り直せるので、生成したものは管理しません。振り分けは `.gitignore` で自動的に行われます。

| 種類 | 例 | 管理方法 |
|---|---|---|
| テキスト・コード | 設定、シーン、脚本、字幕、カット表、cut.md、cut.py、engine | **Git** |
| 資料・図 | 設定画（sheet.png）、相関図、地図、絵コンテ（png / jpg / svg / pdf） | **Git** |
| 動画 | 書き出し、完成映像（mp4 / mov など） | **管理外** |
| 音声 | 生成した BGM・効果音（wav / mp3 など） | **管理外** |
| フォント | ttf / otf | **管理外**（取得スクリプトで入れる） |

- 書き出したものは、必ず `renders/` という名前のフォルダに出します
- 完成映像は外部ストレージに保存し、`master/README.md` に保存場所とハッシュを記録します

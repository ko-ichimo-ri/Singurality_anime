# シンギュラリティ後の私たち

全4編のシリーズ**アニメーション作品**です。設定・構成・シーンから、制作中の素材や完成映像までを、このリポジトリで管理します。

| 公開順 | 編 | フォルダ | コード | 尺の目安 |
|---|---|---|---|---|
| 1 | おっさん編 | [10_ossan/](10_ossan/) | `OS` | 約22分・約280カット |
| 2 | ロボット編 | [20_robot/](20_robot/) | `RB` | 約22分・約280カット |
| 3 | 少女編 | [30_shoujo/](30_shoujo/) | `SJ` | 約22分・約280カット |
| 4 | その後編 | [40_after/](40_after/) | `AF` | 約22分・約280カット |

- おっさん編・ロボット編・少女編は、同じ時間軸で並行して進みます。各編の人物がわずかに干渉しあいます
- その後編は、3編のスピンオフ的な群像劇です
- シリーズ全体で約88分です。見積もりの根拠と映像の仕様は [00_series/production_spec.md](00_series/production_spec.md) にあります

## ディレクトリ構成

```
00_series/        シリーズ全体（4編共通）の設定
  concept/        テーマ、トーン、モチーフ、参考作品
  world/          世界観、年表、技術、組織、場所、用語
  production_spec.md  尺の見積もりと映像の仕様
01_characters/    登場人物（全編共通、1人1ファイル）
02_crossroads/    3編の交差の管理
  intersections/  交差する出来事（1件1ファイル）
03_design/        設定資料（4編共通）：キャラ・小物・美術・色彩
04_sound/         音（4編共通）：主題歌・共通BGM・共通SE
10_ossan/         おっさん編
20_robot/         ロボット編
30_shoujo/        少女編
40_after/         その後編
90_ideas/         まだ整理していないアイデア
99_archive/       ボツにした案（消さずにここへ移す）

```

各編のフォルダの中身は共通です。

```
synopsis.md       あらすじ
plot.md           プロット
concept.md        この編だけのテーマやトーン
outline.md        構成と尺の配分
scenes/
  index.md        シーン一覧
  <ID>_<name>.md  シーン（1シーン1ファイル）
production/       アニメーションの制作物（次の節を参照）
```

## 運用の考え方

- **確定した設定と、検討中の案を分けます。** 確定したものは `00_series/` に、迷っているものは `90_ideas/` に置きます
- **人物はどの編に出る人でも `01_characters/` に置きます。** 複数の編にまたがって登場するためです
- **3編が交わる出来事は `02_crossroads/intersections/` で管理します。** 「実際に何が起きたか」をそこに1か所だけ書き、各編のシーンはそれぞれの視点から描きます

## ID のルール

| 対象 | 形式 | 例 |
|---|---|---|
| シーン | `<編コード>_s<3桁>` | `OS_s010` |
| 交差 | `X<3桁>` | `X010` |
| カット | `<編コード>_c<3桁>` | `OS_c001` |

- シーンと交差の番号は10刻みで振ります。あとで間に追加するときは `OS_s015` のように間の番号を使います
- カットは本編の頭から通し番号です。あとで間に足すときは `OS_c012A` のようにアルファベットを付けます
- ファイル名は `ID_英語やローマ字の短い名前.md`（例：`OS_s010_morning-commute.md`）
- シーンに交差があるときは、シーンファイルに `crossing: X010` と書きます。交差ファイルにも、関わるシーンIDを並べます。こうしておくと、どちらからでもたどれます

## アニメーションの成果物

### 各編の production/

制作の流れ（脚本 → 絵コンテ → カットごとの作画・撮影 → 音 → 編集 → 完成）の順に並べています。

```
production/
  script.md           脚本
  storyboard/         絵コンテ（PDF・画像）。Vコンテ（動画）は Git 管理外
  cut_list.md         カット表：全カットの一覧と工程ごとの進み具合
  cuts/
    _template/        カットフォルダのひな形。新しいカットはこれをコピーして作る
    OS_c001/
      cut.md          カットの情報（尺、カメラ、セリフ、流用元、工程の状態）
      layout/         レイアウト        ┐
      key/            原画              │
      inbetween/      動画              │ 中身は Git 管理外
      color/          仕上げ（彩色）    │（フォルダ構成だけ管理）
      bg/             背景              │
      comp/           撮影（合成）      ┘
  sound/              音（Git 管理外）
    voice/            声
    bgm/              この編だけのBGM
    se/               この編だけの効果音
  edit/               編集の作業ファイル（Git 管理外）
  renders/            書き出し（Git 管理外）
  master/             完成映像の記録（映像そのものは Git 管理外）
```

- 複数の編で使う設定資料は `03_design/`、音は `04_sound/` に置きます
- 3編が交わる場面では、別の編のカットを流用できます。流用するときは `cut.md` の `reuse` に流用元のカットIDを書きます

### ファイルの管理方法

**バイナリファイルは原則 Git の管理外** にします。Git で管理するのは、テキストと、資料・図として残したい画像と PDF だけです。振り分けは `.gitignore` で自動的に行われます。

| 種類 | 例 | 管理方法 |
|---|---|---|
| テキスト | 設定、シーン、脚本、カット表、カット情報（cut.md） | **Git** |
| 資料・図 | 設定画、相関図、地図、カラースクリプト、絵コンテ（png / jpg / svg / pdf） | **Git** |
| 動画 | Vコンテ、書き出し、完成映像（mp4 / mov など） | **管理外** |
| 音声 | 声、BGM、効果音（wav / mp3 など） | **管理外** |
| 作業ファイル | psd / clip / kra / aep / prproj / blend など | **管理外** |
| カットの作画素材 | `cuts/<カット>/` の下のレイアウト〜撮影 | **管理外**（画像でも管理しない） |

- 設定画など、資料として残したいものは、作業ファイル（psd など）から **png や pdf に書き出して** 置きます
- 書き出した映像は、必ず `renders/` という名前のフォルダに出します
- 完成映像は外部ストレージに保存し、`master/README.md` に保存場所とハッシュを記録します
- **管理外のファイルは GitHub にバックアップされません。** 作業ファイルや素材は、クラウドドライブや外付けディスクなどで別途バックアップしてください

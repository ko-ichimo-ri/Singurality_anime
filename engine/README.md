# engine

映像と音を生成する共通の仕組み（Python）です。各カットのスクリプト（`cuts/<カット>/cut.py`）や、キャラクターの定義（`03_design/`）から使います。

## 担当する予定の機能

| 機能 | 内容 |
|---|---|
| 描画 | 図形・SVG パーツ・文字の描画 |
| キャラクター | `03_design/characters/<name>/model.py` を読み込み、関節・表情・口の動きをつける |
| カメラ | PAN・T.U.（寄り）・T.B.（引き）・揺れなど |
| 字幕 | `subtitles.yaml` を読み、日本語版・英語版それぞれの字幕を焼き込む。.srt も書き出す |
| 音 | BGM・効果音の合成とミックス |
| 書き出し | カットを `cut_list.md` の順に並べ、1編を1本の映像にする。日本語版と英語版を別々に書き出す |

使うライブラリや実行方法は、仕組みを作るときにここへ書きます。

## 書き出し先

```
<編>/production/renders/
  cuts/<カットID>/    カットごとの確認用の書き出し
  ja/                 日本語版
  en/                 英語版
```

`renders/` は Git で管理しません。
